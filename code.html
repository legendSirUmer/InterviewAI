Sliding Window Rate Limiter Hard • Tier 1
Algorithmic Concurrency Deque Data Structure

Design and implement an in-memory sliding window rate limiter class in Python that regulates incoming API client requests. Each client is identified by a client_id. The rate limiter must allow up to max_requests within a moving time window of window_seconds.

Example Execution 
limiter = SlidingWindowLimiter(max_requests=3, window_seconds=10)
limiter.allow_request("user_1", timestamp=100) # True
limiter.allow_request("user_1", timestamp=102) # True
limiter.allow_request("user_1", timestamp=108) # True
limiter.allow_request("user_1", timestamp=109) # False (throttled!)
limiter.allow_request("user_1", timestamp=111) # True (100 expired)
Constraints & Invariants
• Time Complexity per request must be amortized O(1).
• Timestamps are non-decreasing integers in epoch seconds.
• Thread-safety locks must be considered for concurrent ASGI workers.

from collections import deque, defaultdict
import time

class SlidingWindowLimiter:
    def __init__(self, max_requests: int, window_seconds: int):
        self.max_requests = max_requests
        self.window_seconds = window_seconds
        self.client_windows = defaultdict(deque)

    def allow_request(self, client_id: str, timestamp: float = None) -> bool:
        # Default to monotonic clock if omitted
        ts = timestamp if timestamp is not None else time.monotonic()
        window = self.client_windows[client_id]
        cutoff = ts - self.window_seconds

        # Evict timestamps falling outside sliding window
        while window and window[0] <= cutoff:
            window.popleft()

        if len(window) < self.max_requests:
            window.append(ts)
            return True
        return False
